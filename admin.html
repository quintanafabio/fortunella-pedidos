Configurar el acceso

El panel guarda los cambios en GitHub, donde vive la página. Para eso necesita una llave de GitHub (se crea una sola vez) y una contraseña que elegís vos. La llave queda guardada cifrada con la contraseña: después, para entrar, alcanza con la contraseña.

  1. Con la cuenta dueña del repo , abrí crear una llave (fine-grained token).
  2. Nombre: Panel Fortunella. Vencimiento: el más largo que permita.
  3. En Repository access elegí Only select repositories y marcá solo este repo.
  4. En Permissions → Repository permissions → Contents elegí Read and write.
  5. Tocá Generate token, copiá la llave y pegala acá abajo.
